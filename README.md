# Zyna

Professional-Grade Laravel Component Package for Flowbite

## Overview

Zyna is a professional-level Laravel component package that wraps Flowbite's UI components in elegant Blade syntax. This package transforms verbose Flowbite HTML markup into simple, maintainable components with zero hardcoded classes, full theme customization, and extensive configuration options.

The package supports both standard Laravel Blade components and Livewire components through a single codebase, with an intelligent installation system that allows users to choose which implementation they need while minimizing code duplication.

## Core Principles

- Zero Hardcoded Classes: All styling and classes defined in central configuration
- Complete Theme Customization: Flowbite-style theme system with full overrides
- Blade-Native API: Simple, expressive component syntax using `<zyna:component>` format
- Full Component Coverage: Wrapping all Flowbite UI components
- Professional Quality Code: Test-driven development with comprehensive test suite
- Elegant JavaScript Integration: Seamless handling of interactive components
- Dual Implementation Support: Support for both standard Blade and Livewire components
- Minimal Code Duplication: Shared logic through base classes and traits
